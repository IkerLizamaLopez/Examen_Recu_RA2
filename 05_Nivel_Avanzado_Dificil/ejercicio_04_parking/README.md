# Ejercicio 04: Parking VIP

## Enunciado
Parking con plazas estandar y VIP.

- 2 plazas estandar
- 1 plaza VIP
- Coches VIP usan plaza VIP si esta disponible, sino esperan
- Coches normales usan plaza estandar, pueden usar VIP si vacia
- Coordinacion compleja con prioridades

## Concepto
Recursos con prioridades y acceso condicional.
