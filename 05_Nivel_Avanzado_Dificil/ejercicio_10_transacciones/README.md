# Ejercicio 10: Transacciones Bancarias Concurrentes

## Enunciado
Multiples clientes hacen transferencias bancarias concurrentes.

- 3 cuentas compartidas
- 5 clientes hacen transferencias aleatorias
- Evitar saldo negativo
- Usar Lock para cada cuenta

## Concepto
Coordinacion de multiples recursos con invariantes.
