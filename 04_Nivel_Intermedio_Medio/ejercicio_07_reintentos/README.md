# Ejercicio 07: Reintentos - Espera con Intentos Limitados

## Enunciado
Implementa reintento de operacion que falla aleatoriamente.

- Cliente intenta acceder a recurso
- Falla el 70% de veces
- Reintenta hasta 3 veces
- Si agota reintentos, se retira

## Concepto
Manejo de fallos y reintentos sin Queue.
