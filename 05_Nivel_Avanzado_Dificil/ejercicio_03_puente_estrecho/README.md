# Ejercicio 03: Puente Estrecho (Clasico)

## Enunciado
Puente de carril unico, coches de Norte y Sur se alternan.

- Coches norte: Atraviesan si no hay coches sur
- Coches sur: Atraviesan si no hay coches norte
- Coordinacion con Condition

## Concepto
Cambio de sentido coordinado entre dos grupos.

## Salida esperada
```
Coche N1 entra (norte: 1, sur: 0)
Coche N2 entra (norte: 2, sur: 0)
Coche N1 cruza y sale (norte: 1, sur: 0)
Coche S1 espera (sur: 1, norte: 1)
Coche N2 cruza y sale (norte: 0, sur: 0)
Coche S1 entra (sur: 1, norte: 0)
```
